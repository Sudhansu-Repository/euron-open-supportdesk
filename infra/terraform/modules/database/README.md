# `database` module

PostgreSQL 16 on RDS for every SupportDesk table: organisations, users, inboxes, customers, tickets and messages, the knowledge base with its chunk embeddings (pgvector), AI turns with their cost ledger, jobs (the outbox the workers claim with leases), analytics rollups and the audit log. Uploaded files live in S3; rows keep only their key.

- `vector` (pgvector) is available on RDS for PostgreSQL 16; the first migration runs `CREATE EXTENSION IF NOT EXISTS vector` as the master user, so nothing is configured here.
- Private subnets, no public access, ingress added per consumer security group (the api, the worker and migrate).
- Encrypted with the CMK, `rds.force_ssl`, Performance Insights, Enhanced Monitoring, `idle_in_transaction_session_timeout` so a crashed task cannot hold a claimed job's lock.
- The master password is generated by Terraform and only ever stored inside `DATABASE_URL` in Secrets Manager.

## Inputs

| Name | Description | Type | Default |
|---|---|---|---|
| `name_prefix` | Prefix for every resource name. | `string` | required |
| `vpc_id` | VPC id. | `string` | required |
| `subnet_ids` | Private subnets for the DB subnet group (2+ AZs). | `list(string)` | required |
| `kms_key_arn` | CMK for storage and Performance Insights. | `string` | required |
| `database_name` | Initial database name. | `string` | `"supportdesk"` |
| `master_username` | Master user name. The password is generated by Terraform and only ever stored inside DATABASE_URL in Secrets Manager. | `string` | `"supportdesk_admin"` |
| `engine_version` | PostgreSQL major (or major.minor) version. | `string` | `"16"` |
| `instance_class` | Instance class. Graviton (t4g/m7g/r7g) recommended. | `string` | `"db.t4g.medium"` |
| `allocated_storage` | Initial gp3 storage in GiB. | `number` | `50` |
| `max_allocated_storage` | Storage autoscaling ceiling in GiB. Messages and chunk embeddings grow with every conversation and upload, so leave headroom. | `number` | `500` |
| `multi_az` | Synchronous standby in a second AZ. | `bool` | `false` |
| `backup_retention_days` | Automated backup retention. | `number` | `7` |
| `deletion_protection` | Block accidental deletion. | `bool` | `true` |
| `monitoring_interval` | Enhanced Monitoring granularity in seconds (0 disables): 1, 5, 10, 15, 30 or 60. | `number` | `60` |
| `skip_final_snapshot` | Skip the final snapshot on destroy (throwaway envs only). | `bool` | `false` |

## Outputs

| Name | Description |
|---|---|
| `address` | DB hostname. |
| `port` | DB port. |
| `database_name` | Database name. |
| `instance_identifier` | RDS instance identifier (CloudWatch dimension). |
| `security_group_id` | DB security group; consumers add ingress rules against it. |
| `master_username` | Master username. |
| `connection_url` | DATABASE_URL for the API (SQLAlchemy asyncpg dialect, TLS required). Pass it to the secrets module, never to plain task environment. |
